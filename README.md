# Velocity Rush 3D

مشروع لعبة قيادة وسباق أركيد ثلاثية الأبعاد تعمل دون اتصال ومبنية على **Godot 4.7.2**. من شاشة البداية اختر بين نمطين:

- **سباق الحلبة:** ثلاث لفات، منافسون آليون، نيترو، عقبات، نقاط ونتيجة قابلة للإعادة.
- **القيادة الحرة:** مدينة ثلاثية الأبعاد مولّدة داخل Godot، شبكة شوارع متقاطعة متعددة المسارات، أرصفة ومعابر وإشارات مرور، مبانٍ مرتفعة ومنخفضة مع واجهات فنادق ومطاعم، وسيارات مرور تسير في اتجاهين وتنعطف عبر الشبكة.

تضم اللعبة ثلاث سيارات خيالية قابلة للاختيار، تسارعًا وفرملة وتوجيهًا، كاميرا مطاردة، واجهة عربية وأزرار لمس. استُخدم تجميع `MultiMesh` لعناصر المدينة المتكررة لتقليل كلفة الرسم. الأيقونة ومواد الطريق مخصصة للمشروع.

> أسماء السيارات **Aerion GT-R** و**Vortex SV-X** و**Terra Rally S** خيالية. لا تحتوي السيارات على شعارات Ferrari أو Lamborghini أو Toyota، ولا تدّعي أنها طرازات مرخصة أو نسخ دقيقة. استعمل أصول العلامات الأصلية فقط إذا امتلكت حقوقها.

## تشغيل المشروع

1. ثبّت **Godot 4.7.2 Stable**.
2. افتح `project.godot` في Godot ثم شغّل المشهد الرئيسي.
3. اختر السيارة ونمط اللعب من القائمة.
4. على الكمبيوتر: **W** أو **↑** للتسارع، **S** أو **↓** أو **Space** للفرامل، **A/D** أو **←/→** للتوجيه، **Shift** للنيترو في سباق الحلبة، و**Esc/P** للإيقاف والاستئناف.
5. على الهاتف: استخدم أزرار اللمس للتوجيه والتسارع والفرامل والإيقاف؛ يظهر زر النيترو في نمط الحلبة فقط.

يمكن كتم الصوت من القائمة، ويُحفظ الاختيار محليًا. المدينة والسباق يعملان دون اتصال.

## البناء على GitHub Actions (من دون Windows Runner)

لا تحتاج إلى Windows Runner أو Unreal Engine أو Android Studio. ارفع مجلد المشروع إلى مستودع GitHub مع الحفاظ على بنية الملفات، ثم افتح **Actions**. يعمل Workflow تلقائيًا عند الدفع إلى `main` أو `master` أو عند طلب دمج، ويمكن تشغيله يدويًا عبر **Run workflow**.

بعد نجاح **Build Android APK**، نزّل الـArtifact باسم `Velocity-Rush-3D-Android-APK` من صفحة التشغيل. يقدمه GitHub كملف ZIP؛ فك ضغطه ثم ثبّت `VelocityRush3D.apk` نفسه، ولا تحاول تثبيت ملف ZIP. هذا إصدار **Debug** للاختبار موقّع بمفتاح مؤقت داخل Runner، وليس مفتاح نشر للمتجر.

يستخدم Workflow Ubuntu 24.04 وJava 17 وAndroid SDK/NDK وGodot 4.7.2. يدعم APK بنيتي **ARM64 وARMv7**. لم يُنشأ APK هنا؛ يلزم نجاح تشغيل GitHub Actions في مستودعك لإثبات البناء.

## فحوص محلية

```bash
godot --headless --editor --path . --quit --import
godot --headless --path . --script res://tests/smoke_test.gd
```

يفحص اختبار الدخان تحميل المشروع، عناصر المدينة والمرور، حركة اللاعب، الإيقاف والاستئناف والعودة للقائمة، ثم حلقة سباق الحلبة. لتصدير Web يدويًا بعد تثبيت قوالبه:

```bash
godot --headless --path . --export-release "Web" dist/index.html
```

انظر `docs/` لتفاصيل البناء والتحويل والبنية والأداء والحقوق.
