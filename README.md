# Velocity Rush 3D

مشروع لعبة سباق أركيد ثلاثية الأبعاد، يعمل دون اتصال ومبني على **Godot 4.7.2**. يتضمن ثلاث سيارات GLB خيالية، حلبة قابلة للقيادة، منافسين آليين، التقاطات نيترو وعقبات، تسارعًا وفرملة وانجرافًا، واجهات البداية والإيقاف والنتيجة والإعادة، HUD عربيًا، وأيقونة تطبيق.

> السيارات في المشروع خيالية بأسماء **Aerion GT** و**Vortex SVX** و**Terra Rally S**. لا تحتوي على شعارات Ferrari أو Lamborghini أو Toyota، ولا تدّعي أنها طرازات مرخصة أو نسخ دقيقة. استخدم فقط أصول العلامات الأصلية إذا توفرت لك حقوقها.

## تشغيل المشروع

1. ثبّت Godot **4.7.2 Stable**.
2. افتح `project.godot` في Godot، ثم شغّل المشهد الرئيسي.
3. على الكمبيوتر: **W** أو **↑** للتسارع، **S** أو **↓** للفرامل، **A/D** أو **←/→** للتوجيه، **Shift/Space** للنيترو، و**Esc** للإيقاف المؤقت.
4. على الهاتف: أزرار اللمس الظاهرة للتوجيه والتسارع والفرامل والنيترو.

السباق محلي وغير متصل. يمكن كتم الصوت من داخل الواجهة؛ يحفظ الاختيار محليًا.

## البناء على GitHub Actions (من دون Windows Runner)

لا تحتاج إلى Windows Runner أو Unreal Engine أو Android Studio. ارفع مجلد المشروع إلى مستودع GitHub مع الحفاظ على بنية الملفات، ثم افتح **Actions**. يعمل Workflow تلقائيًا عند الدفع إلى `main` أو `master`، أو طلب دمج، كما يمكن تشغيله يدويًا عبر **Run workflow**.

بعد نجاح **Build Android APK**، نزّل الـArtifact باسم `Velocity-Rush-3D-Android-APK` من صفحة التشغيل. يحتوي على `VelocityRush3D.apk`. هذا إصدار **Debug** للاختبار، موقّع بمفتاح مؤقت داخل Runner؛ ليس مفتاح نشر للمتجر ولا يُحفظ في المستودع.

يستخدم Workflow Ubuntu 24.04، وJava 17، وAndroid SDK/NDK، وGodot 4.7.2 وقوالب التصدير المتوافقة. يدعم APK بنية **ARM64**. لم أُنشئ APK هنا؛ البناء الفعلي يُثبت فقط بعد نجاح تشغيل GitHub Actions في مستودعك.

## فحص محلي سريع

```bash
godot --headless --editor --path . --quit --import
godot --headless --path . --script res://tests/smoke_test.gd
```

يفحص اختبار الدخان تحميل المشهد، تهيئة الحلبة وHUD، تسارع اللاعب ووجود أربعة منافسين. لتصدير Web يدويًا بعد تثبيت قوالبه:

```bash
godot --headless --path . --export-release "Web" dist/index.html
```

تفاصيل البناء والحقوق وبنية المشروع موجودة في `docs/`.
