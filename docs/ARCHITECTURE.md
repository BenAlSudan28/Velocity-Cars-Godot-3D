# بنية اللعبة

- `scenes/race/`: المشهد الرئيسي ومشاهد السيارة والخصم والعقبة والتقاط النيترو والحلبة.
- `scripts/race/race_main.gd`: مالك تدفق اللعب؛ قائمة اختيار النمط، بدء السباق أو المدينة، الإيقاف والاستئناف وإعادة التشغيل والنتيجة.
- `scripts/race/race_track.gd` و`route_math.gd`: مسار Catmull–Rom المغلق، إحداثيات الطريق، السطح والعلامات والحواجز.
- `racer.gd` و`player_driver.gd` و`rival_driver.gd`: حركة سيارات السباق والسرعة والتوجيه والنيترو وذكاء الخصوم.
- `scripts/city/`: `CityConfig` لشبكة الشوارع وحدودها، `FreeDriveController` لسيارة اللاعب، `CityTrafficCar` للمركبات الآلية، `CityBuildingFactory` للمباني والواجهات، و`FreeDriveCity` لتجميع المشهد والإشارات والطرق.
- `scenes/city/free_drive_city.tscn`: مشهد مستقل للمدينة يُنشأ عند اختيار القيادة الحرة ويُحرر عند العودة للقائمة.
- شبكة المدينة تستخدم خمسة محاور طرق متقاطعة في كل اتجاه؛ خطوط المسارات والمعابر والأرصفة وإشارات المرور والإنارة والمباني المتكررة مجمعة بواسطة `MultiMesh` لتقليل عدد عناصر الرسم.
- `car_catalog.gd` و`car_visual.gd`: ربط السيارات الخيالية بملفات GLB وعرض بديل مبسط عند تعذر استيراد نموذج.
- `collision_manager.gd` و`score_system.gd` و`difficulty_manager.gd`: حساب تصادمات الحلبة والنقاط وتدرج الصعوبة.
- `race_hud.gd` و`touch_controls.gd` و`race_theme.gd`: واجهة عربية، شاشات اللعب والتحكم باللمس؛ يخفي نمط المدينة زر النيترو.
- `audio_manager.gd` و`settings_store.gd`: صوت محلي، نبرة محرك متغيرة، كتم الصوت وتفضيلات اللاعب.
- `assets/race/`: ملفات GLB وOGG محلية؛ لا يعتمد تشغيل اللعبة على الإنترنت.
- `assets/icons/`: أيقونة أصلية وملفات PNG وSVG وطبقات adaptive.
- `.github/workflows/build.yml`: استيراد الموارد، اختبار حلقة اللعب، بناء APK Debug والتحقق منه ورفع الـArtifact.

تظل محاكاة اللعب محلية وغير متصلة؛ لا توجد خدمة تسجيل دخول أو خادم أو ترتيب شبكي. السيارات خيالية ولا تحمل شعارات الشركات.
