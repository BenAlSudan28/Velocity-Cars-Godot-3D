# رفع المشروع إلى GitHub

احتفظ بالبنية النسبية عند رفع ملفات المشروع. يجب أن يكون `project.godot` في جذر المستودع، وألا تُرفع مجلدات `.godot/` أو `.git/` أو ملفات APK المؤقتة. يضم الأرشيف الذي ستستلمه مصدر اللعبة والأصول اللازمة للتشغيل، أما APK فينتجه GitHub Actions بعد الرفع.

يمكن تغيير اسم المستودع والفرع بحرية؛ إعداد Workflow يستجيب إلى `main` و`master` ويضم خيار تشغيل يدوي. إذا كان المستودع يستخدم فرعًا افتراضيًا مختلفًا، أضف اسمه إلى قائمة الفروع في `build.yml`.
