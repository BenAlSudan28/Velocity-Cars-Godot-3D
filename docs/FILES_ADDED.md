# ملفات نسخة Godot المحوّلة

تضم الحزمة **32 ملف GDScript** داخل `scripts/`: 25 لوحدات سباق الحلبة، و5 لوحدات المدينة والقيادة الحرة، وملفي دعم للمشروع. كما تحتوي **8 مشاهد Godot** (7 للحلبة والسيارات وعناصر السباق، ومشهد مستقل للمدينة). يوجد إلى جانب ذلك إعداد المشروع والتصدير لـAndroid وWeb، وGitHub Actions، ووثائق البناء والتحويل والأداء، واختبارات الدخان واللقطات، وثلاثة نماذج GLB مع خاماتها، وثمانية ملفات OGG، وخط عربي مع ترخيصه، وأيقونات تطبيق مخصصة.

المدينة تضيف شبكة شوارع متقاطعة، معابر وأرصفة وإشارات مرور، واجهات مطاعم وفنادق، وثماني سيارات مرور آلية تسلك مسارات متعاكسة. واجهة البداية تتيح اختيار سباق الحلبة أو القيادة الحرة. استخدم Godot 4.7.2، ولا تخلط أصول Unreal الثنائية أو ملفات `.uasset` مع مصدر Godot.
