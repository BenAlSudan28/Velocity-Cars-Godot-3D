# ملفات نسخة Godot المحوّلة

تتضمن الحزمة **25 وحدة GDScript للسباق** و**7 مشاهد Godot** منفصلة، إلى جانب إعدادات المشروع والتصدير لـAndroid وWeb، وGitHub Actions، ووثائق البناء والتحويل، واختبارات دخان، وثلاثة نماذج GLB مع خاماتها، وثمانية ملفات OGG، وخطًا عربيًا مع ترخيصه، وأيقونات تطبيق مخصصة. يتجاوز ذلك شرط إضافة 20 ملفًا تطويريًا مستقلًا.

الهدف من التقسيم هو تسهيل التوسعة داخل Godot بدل تجميع كل التنفيذ في ملف واحد. استخدم Godot 4.7.2؛ لا تخلط أصول Unreal الثنائية أو `.uasset` مع المشروع الجديد.
