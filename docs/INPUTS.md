# التحكم

على لوحة المفاتيح، `W` أو السهم للأعلى للتسارع، و`S` أو السهم للأسفل أو `Space` للفرامل. التوجيه بـ`A/D` أو الأسهم اليمنى واليسرى، والنيترو بـ`Shift`، والإيقاف والاستئناف بـ`Esc` أو `P`. تهيّأ خريطة الإدخال عند تشغيل اللعبة.

على الهاتف تظهر أزرار لمس كبيرة للتوجيه والتسارع والفرامل والنيترو والإيقاف. الضغط والإفلات يحدّثان حالة التحكم في المحاكاة مباشرة، وتُصفّر حالات اللمس عند الإيقاف أو تبديل الشاشة حتى لا يبقى زر عالقًا.
