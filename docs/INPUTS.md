# التحكم

## قائمة البداية

اختر السيارة باستخدام زري **السابق** و**التالي**، ثم اختر **سباق الحلبة** لبدء ثلاث لفات مع منافسين ونيترو، أو **قيادة حرة** للدخول إلى المدينة والتجول دون نتيجة زمنية أو نهاية مفروضة. يمكن كتم الصوت أو تشغيله من القائمة، ويُحفظ الاختيار محليًا.

## الكمبيوتر

| الفعل | المفاتيح |
| --- | --- |
| تسارع | `W` أو السهم لأعلى |
| فرامل | `S` أو السهم لأسفل أو `Space` |
| توجيه يسار / يمين | `A` / `D` أو السهمان يسار / يمين |
| نيترو (سباق الحلبة فقط) | `Shift` |
| إيقاف مؤقت / استئناف | `Esc` أو `P` |
| بدء النمط الافتراضي من القائمة | `Enter` |

## الهاتف

استخدم أزرار اللمس الظاهرة للتوجيه والتسارع والفرامل والإيقاف المؤقت. يظهر زر النيترو في سباق الحلبة فقط. يحتفظ النمطان باتجاه الشاشة الأفقي.

## قواعد النمطين

في الحلبة، تجنب المنافسين والعقبات واجمع التقاطات النيترو وأكمل اللفات الثلاث قبل الوصول إلى شاشة النتيجة. في المدينة، قُد ضمن شبكة الطرق المتقاطعة؛ تتباطأ السيارة خارج شبكة الطرق، وتتحرك مركبات المرور في اتجاهين وتنعطف عند التقاطعات. يمكنك إيقاف أي نمط واستئنافه أو إعادته والعودة إلى قائمة اختيار النمط.
